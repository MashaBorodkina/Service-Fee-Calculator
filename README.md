# Service-Fee-Calculator

This repository includes all projects from my freelance work. It consists of several folders, which are grouped based on their purpose and/or programming languages.

## Source
The calculator was created to calculate the total cost of services. The total is the sum of the products of the quantity and the price of each service.
## Task
Users can calculate the cost of services using the on-site calculator, fill out the form with their information, and submit the order to the provider. The submitted email will include the form data, calculator results, and attached files.
## Technologies used
HTML, CSS, JavaScript, PHP
